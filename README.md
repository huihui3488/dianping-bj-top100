# 北京餐厅 Top100 · 大众点评数据流水线

课程项目「大众点评北京餐厅 Top100」的成果与代码整合站点。静态页面，零外部依赖，
断网也能完整打开——答辩现场不需要联网。

## 四个页面

| 页面 | 内容 |
|---|---|
| `index.html` | 总览：四个核心数字、四段流水线、分工与交付 |
| `results.html` | 成果：Top100 明细表（可搜索/筛选/排序）、7 张图表、口径实验台、对照实验表 |
| `code.html` | 代码：三个脚本的完整源码（带行号与语法着色）、关键决策、16 条答辩问答 |
| `method.html` | 口径与局限：公式、三道闸门、权重论证、相关性检验、七条局限声明 |

采集日期 2026-10-15，候选 150 家，入榜 100 家。

## 口径

```
综合分 = 0.625 × minmax(评分) + 0.375 × minmax(ln(1 + 评论数))
```

三道闸门：评论数门槛 2000 → 双维度加权排序（同分依次比评分、评论数、店名）→ 品牌限额每家 1 席。

权重来源：原设计为「评分 0.50 / 评论数 0.30 / 客流量 0.20」，客流量维度因数据源不存在被删除，
剩余两维按原 5:3 比例等比放大到合计 1.0。

## 如何更新

`assets/data.js` 与 `assets/code.js` 由仓库外的 `build_site.py` 生成。
成员 3 的产物如有更新，替换 `top100.csv` / `cuisine_full.csv` 后重跑：

```bash
python build_site.py
```

构建脚本会同时做一次端到端校验：用与 `build_ranking.py` 等价的实现重算整条流水线，
并断言名次与 `top100.csv` 完全一致（当前 100/100）。校验不过会直接打印差异，不会静默生成错数据。

## 兼容性

- 无 CDN、无 Web Font、无前端框架，`fetch` 也未使用（数据以 `assets/data.js` 全局注入），
  因此**双击 `index.html` 用 `file://` 打开同样正常**。
- 打印样式已处理（`@media print` 隐藏导航与实验台、取消代码块高度限制），可直接导出 PDF。
